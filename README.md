# Merethe's Movie Theatre Reservation System

This is a simple Java movie theater program that lets the user view the seats and reserve or cancel a seat.

## How It Works

The seating chart has 4 rows with 5 seats in each row.

* `O` means the seat is available.
* `X` means the seat is taken.
* You can view the seating chart.
* You can reserve an available seat.
* You can cancel a reservation.
* If a seat is already taken, the program suggests other available seats.

## How to Run

Compile and run the program with:

```bash
javac MovieTheater.java
java MovieTheater
```
